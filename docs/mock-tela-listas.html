Falhas simuladas

Ligadas, valem para a próxima operação daquele tipo. Cobrem os requisitos “Validar nome da lista”, “Tratar falha ao carregar”, “Tratar falha ao salvar ou excluir” e “Tratar lista que deixou de existir”; os códigos E0x são só rótulos do mock.

Latência 500 ms

Log (View → Controller → Model)

Roteiro sugerido

  1. Criar: “+”, aceitar “Feira dd/mm” → vai para o topo e o contador sobe.
  2. E01: apagar o nome (ou só espaços) e salvar → aviso, modal fica com o texto.
  3. E02: ligar “Desligar MaxLength”, colar um nome longo → aviso.
  4. Renomear / Excluir pelo ⋮ e pelo toque longo; conferir a mensagem com 0, 1 e N itens (preset “Casos limite”).
  5. Excluir a última lista → estado vazio, “+” some.
  6. E03–E06: ligar cada falha e repetir a operação.
  7. Rolagem: preset “Muitas”, arrastar começando em cima de um card → não deve abrir o card; último card não fica atrás do “+”.
  8. Voltar do Android com modal aberto, com menu aberto e sem nada aberto.
